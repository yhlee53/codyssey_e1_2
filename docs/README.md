# 퀴즈 게임 (Quiz Game)

내가 만드는 첫 번째 프로그램, **터미널에서 동작하는 퀴즈 게임**입니다.

## 🎯 프로젝트 개요

**Python의 기본 문법과 객체 지향 프로그래밍(OOP)을 배우기 위한 실습 프로젝트**

프로그램을 직접 처음부터 끝까지 구현하면서 코드 작성, 데이터 저장, 그리고 Git 버전 관리까지 경험합니다.

### 주요 특징
- 🎮 **메뉴 기반 대화형 게임** - 사용자가 원하는 기능을 선택해서 실행
- 🔄 **데이터 영속성** - 프로그램을 종료해도 퀴즈와 점수가 JSON으로 저장됨
- 🏗️ **객체 지향 구조** - 클래스를 활용한 체계적인 코드 설계
- 🛡️ **견고한 예외 처리** - 사용자 입력 오류 및 파일 손상에 대응

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎯 **퀴즈 풀기** | 보유한 퀴즈 중 랜덤으로 출제되며, 정답 여부를 판정 |
| ➕ **퀴즈 추가** | 새로운 퀴즈와 선택지를 입력하여 저장 |
| 📋 **퀴즈 목록** | 저장된 모든 퀴즈와 주제를 확인 |
| 🏆 **점수 확인** | 각 주제별 최고 점수 조회 |
| 🚪 **프로그램 종료** | 데이터를 저장하고 안전하게 종료 |

---

## 🚀 실행 방법

### 1단계: 프로그램 실행
```bash
python main.py
```

### 2단계: 메뉴 선택
```
============================================================
       🎮 퀴즈 게임 메뉴 (퀴즈 6개, 최고점수 66점) 🎮
============================================================
1. 🎯 퀴즈 풀기
2. ➕ 퀴즈 추가
3. 🗑️  퀴즈 삭제
4. 📋 퀴즈 목록
5. 🏆 최고 점수 확인
6. 🚪 종료
============================================================

선택: _
```

### 3단계: 기능 이용
- 번호를 입력하여 원하는 기능을 선택합니다.
- 각 기능의 안내에 따라 진행합니다.
- 프로그램을 종료해도 데이터는 자동 저장됩니다.

## 🗂️ 데이터 파일 설명

### `state.json`
프로그램의 모든 데이터를 JSON 형식으로 저장합니다.

**예시 구조:**
```json
{
  "quizzes": [
    {
      "question": "파이썬은 몇 년에 만들어졌을까?",
      "choices": ["1989년", "1991년", "1995년", "1999년"],
      "answer": 1
    }
  ],
  "best_score": 100
}
```

**특징:**
- UTF-8 인코딩으로 저장
- 프로그램 실행 시 자동으로 로드
- 파일이 없거나 손상되면 기본 데이터로 자동 복구
